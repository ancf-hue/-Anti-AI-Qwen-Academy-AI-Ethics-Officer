## 🌟 О проекте

**Anti-AI Qwen Academy** — это бесплатная, полностью офлайн-платформа для подготовки специалистов по этике искусственного интеллекта. Проект объединяет теоретические знания и практические инструменты, необходимые для обеспечения ответственного, прозрачного и социально-ориентированного внедрения ИИ-систем.

### 🎯 Ключевые особенности

| Особенность | Описание |
|-------------|----------|
| 🔐 **100% Offline** | Работает без интернета после загрузки |
| 🌍 **Bilingual** | Русский и английский языки интерфейса |
| 🔊 **Voice Narration** | Голосовое озвучивание уроков |
| 📱 **PWA Ready** | Можно установить как приложение |
| 💾 **Local Storage** | Прогресс сохраняется в браузере |
| 🎓 **Certificate** | Сертификат с уникальным ID после завершения |

## 📋 Содержание курса

### 10 дней обучения:

| День | Тема | Ключевые навыки |
|------|------|-----------------|
| 1 | ⚖️ Введение в профессию | Роль специалиста по этике ИИ, 3 этических принципа |
| 2 | 🔍 Этические фреймворки | Утилитаризм, деонтология, этика добродетелей |
| 3 | 🤖 Жизненный цикл ИИ | Точки этического вмешательства, чек-листы |
| 4 | ⚠️ Выявление смещений | Bias detection, fairness metrics, аудит данных |
| 5 | 👥 Стейкхолдеры | Картирование групп влияния, engagement strategies |
| 6 | 📋 Политики ИИ | SMART-политики, процедуры, роли, метрики |
| 7 | ⚖️ Регуляторное соответствие | EU AI Act, ISO 42001, GDPR, 152-ФЗ |
| 8 | 📊 Оценка воздействия | Социальные, экологические, экономические последствия |
| 9 | 📁 Портфолио Qwen | Форматы отчётности, этический паспорт |
| 10 | 🏆 Финальный экзамен | 10 вопросов → сертификат |

## 🛠️ Инструменты

### Встроенные инструменты специалиста по этике ИИ:

1. **🔍 Конструктор этического аудита**
   - Описание ИИ-системы
   - Выбор типа системы и уровня риска
   - Оценка справедливости
   - Экспорт в Qwen формате

2. **📋 Генератор политик**
   - Создание политики ответственного ИИ
   - Принципы и процедуры
   - Экспорт в JSON

## 📚 Библиотека

- **Ролевая документация:** обязанности, KPI, инструментарий
- **Регуляторные фреймворки:** EU AI Act, GDPR, ISO 42001, 152-ФЗ
- **Навыки:** Hard skills & Soft skills
- **Карьерные пути:** где работают специалисты по этике ИИ

## 🎓 Сертификация
